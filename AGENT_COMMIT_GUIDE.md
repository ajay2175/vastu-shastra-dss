## Commit Message Format

```
<type>(<scope>): <subject>

<body>

Generated by: Agent <agent_id>
Sprint Wave N: <phase>
```

**Types**: feat, fix, docs, style, refactor, test, chore
**Scope**: component name (api, rag, vdb, etc.)

## GitHub Workflow

After each agent commits:
1. GitHub Actions runs tests automatically
2. If tests pass: ✅ commit stays
3. If tests fail: 🔴 Fix required before next agent starts
4. Sprint tracking document auto-updates
5. CI/CD pipeline validates all changes

## Monitoring

**Real-time progress tracking:**
```bash
# Watch branch activity
gh run watch

# Check latest commits
git log --oneline -10

# Monitor sprint status
cat SPRINT_TRACKING.md
```

## Emergency Fixes

If an agent introduces breaking changes:
```bash
# Revert last commit
git revert HEAD

# Force fix before continuing
git add <files>
git commit -m "fix: <description>"
git push origin main
```

✅ Every piece of work is tracked in git
